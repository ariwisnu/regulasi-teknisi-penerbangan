# Surveillance — Unit Maumere (MOF)

> **Catatan alat:** Unit Maumere **belum punya fasilitas surveillance** (tidak ada PSR/SSR/MSSR,
> ADS-B, MLAT) per data alat (seed MOFEngineering: hanya VHF A/G, Voice Recorder, DVOR, DME).
> Folder ini diisi untuk **kelengkapan disiplin** dan relevan bila unit memasang ADS-B/MLAT, atau
> untuk teknisi surveillance di unit lain.

## Regulasi

| Nomor | Judul | Status |
|---|---|---|
| [PR 6 DJPU 2024](PR-6-DJPU-2024.md) | Alokasi SAC/SIC/II Code, ICAO 24-bit, ELT 406 MHz, Location Indicator | **aktif** |
| [KP 243/2014](KP-243-2014.md) | ~~Izin Kode SSR Mode-S & ELT 406 MHz~~ | 🚫 dicabut |

## Spesifikasi & pemeliharaan surveillance

Spesifikasi teknis surveillance (PSR, MSSR Mode-S, ADS-B, MLAT, ATC Automation) ada di
[KP 103/2015 (MOS 171-02)](../umum/KP-103-2015.md); persyaratan kinerja + pemeliharaan di
[PR-DJPU 08/2025 (MOS 172-03)](../umum/PR-DJPU-8-2025.md) BAB II. Lisensi/rating: Part 69
([PR 18/2023](../lisensi-rating/PR-18-2023-MOS-69-02.md)).
