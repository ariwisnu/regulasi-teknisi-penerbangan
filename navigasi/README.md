## Catatan Status Operasional

- **DVOR status U/S** di data operasional Maumere, konsisten dengan **AIP SUP 39/2024 (AIRAC)**:
  *"Unserviceability of MOF VOR/DME at Fransiskus Xaverius Seda Airport — Maumere"*.
- Pengembalian ke serviceable butuh ground check (KP 103/2015 + KP 35/2019) **dan** flight inspection
  (PM 22/2015 / Doc 8071).

## Catatan Teknis

- DVOR (Doppler VOR) + DME co-located = nav aid azimuth + jarak. Konfigurasi **DUAL** (main/standby).
- Parameter & toleransi verbatim (course alignment, modulation, DME delay/reply efficiency) **belum
  diisi** — tarik dari PDF KP 103/2015 atau SWORD AirNav, bukan dari ingatan (nilai keselamatan).
