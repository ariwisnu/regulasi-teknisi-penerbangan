## Kategori & Interval Pemeliharaan (BAB III)

Pemeliharaan = **perencanaan** + **pelaksanaan** + **pencatatan riwayat** (§3.2.1). Pelaksanaan terdiri
dari **preventive** (pencegahan) + **corrective** (perbaikan) (§3.2.3).

#### Preventive — pencegahan (§3.2.6–3.2.10)

| Jenis | Interval | Tujuan |
|---|---|---|
| Harian | setiap hari | kondisi operasional peralatan (via sistem aplikasi IT) |
| Mingguan | seminggu sekali | kesiapan operasional peralatan utama vs cadangan |
| Bulanan | sebulan sekali | kinerja & nilai parameter (built-in test equipment / external tool) |
| Tahunan | setahun sekali | kondisi fisik & fungsi tiap bagian sistem peralatan |

**Pengecualian (§3.2.12):** preventive boleh **paling lama 3 bulan sekali** untuk — VHF-A/G portable;
Voice recorder ≤ 8 channel (PC + back-up + UPS); teleprinter (PC + UPS).

#### Corrective — perbaikan (§3.2.13–3.2.14)

Mengembalikan fungsi fasilitas yang gangguan/rusak ke kondisi normal. Kegiatan: analisis kerusakan →
penggantian komponen/modul/unit → perbaikan modul/bagian/perangkat lunak → modifikasi.

Metode preventive (harian–tahunan) wajib disetujui Direktur & dituang di **Manual Operasi** (§3.2.11).
Riwayat pemeliharaan dicatat per fasilitas, ditandatangani penanggung jawab (§3.2.21–3.2.22). Hasil
evaluasi dilaporkan (BAB V) dan dicatat di **Facility Log Book** (BAB IV).
