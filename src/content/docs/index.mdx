## Kenapa repo ini

<CardGrid>
  <Card title="Status selalu ketahuan" icon="approve-check">
    Tiap regulasi ditandai **aktif / dicabut / diubah** + apa yang mencabutnya. Ngikutin regulasi
    basi = bahaya (salah lisensi, salah parameter). Ini value utama.
  </Card>
  <Card title="Per cara kerja teknisi" icon="setting">
    Disusun per **disiplin & alat** (lo pegang ILS → butuh apa), bukan per nomor dokumen.
  </Card>
  <Card title="Tertaut ke sumber resmi" icon="document">
    Tiap halaman menautkan **JDIH Kemenhub / SWORD AirNav** — selalu ngarah ke versi resmi.
  </Card>
  <Card title="Git = pelacak versi" icon="github">
    Tiap perubahan regulasi jadi commit. Teknisi lain bisa kontribusi lewat Pull Request.
  </Card>
</CardGrid>

:::caution[Bukan dokumen resmi]
Repo ini alat bantu terkurasi, **bukan** dokumen resmi AirNav/Kemenhub. Untuk keputusan operasional,
selalu rujuk teks resmi di [JDIH Kemenhub](https://jdih.dephub.go.id/).
:::
